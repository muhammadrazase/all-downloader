# How to Add the SnapVidly Extension to Chrome

Two ways: **(A)** from the Chrome Web Store (for everyone, once published), or **(B)** load it manually (for testing before it's published, or if you have the folder).

---

## A. From the Chrome Web Store (recommended)

1. Go to the SnapVidly listing: **`https://chromewebstore.google.com/detail/snapvidly/<id>`**
   (or click **“Add to Chrome”** on `https://snapvidly.com/browser-extension`).
2. Click **“Add to Chrome”**.
3. In the popup, click **“Add extension”**.
4. **Pin it** so it's always visible: click the **puzzle-piece icon** in the toolbar → click the **pin** next to SnapVidly.
5. Done. ✅

Works the same in **Chrome, Brave, Edge and Opera** (all Chromium browsers).

---

## B. Install manually (Load unpacked)

Use this to test the extension before it's on the store, or if you were given the `snapvidly-extension` folder.

1. Open **`chrome://extensions`** (paste it in the address bar).
2. Turn on **Developer mode** (toggle, top-right).
3. Click **“Load unpacked”**.
4. Select the **`snapvidly-extension`** folder.
5. SnapVidly appears in your extensions list — **pin it** (puzzle icon → pin).

> Note: “Load unpacked” extensions show a small “Developer mode extensions” reminder on each Chrome start — that's normal for manually-loaded extensions.

---

## How to use it

1. Open any video — **TikTok, YouTube, Instagram, Facebook, X (Twitter), Reddit, Pinterest, Vimeo, Twitch, Tumblr, LinkedIn**.
2. A **“⬇ SnapVidly”** button appears at the bottom-right of the page (only on real video pages).
3. **Click it** — SnapVidly opens in a new tab with the video already loaded.
4. Pick a quality (**HD / 4K / MP3**) and **download**.

You can also click the **SnapVidly toolbar icon** on any video page to do the same thing.

---

## Troubleshooting

- **No button on the page?** It only shows on actual video pages (a watch/reel/status URL), not on feeds or home pages. Open the specific video first.
- **Button covered by the site's own controls?** Use the **toolbar icon** instead.
- **Nothing happens on click?** Make sure pop-ups aren't blocked for the site; the extension opens SnapVidly in a new tab.
- **Updating the extension (manual install):** on `chrome://extensions`, click the **refresh/reload** icon on the SnapVidly card after changing files.

---

## Privacy & permissions

SnapVidly uses **only the `activeTab` permission** — it reads the current tab's URL **when you click**, and opens SnapVidly with it. It does **not** track you, run in the background, or download anything itself. The download happens on `snapvidly.com`.
